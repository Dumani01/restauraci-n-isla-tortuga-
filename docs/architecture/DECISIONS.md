# DECISIONS

## DEC-001 Datos locales para el prototipo

Durante la base académica se usarán `db.json` y persistencia local. La conexión a un backend real queda fuera hasta confirmar los requisitos del equipo.

## DEC-002 IA con revisión humana

La IA podrá resumir registros y detectar información incompleta, pero no diagnosticar enfermedades ni recomendar acciones biológicas de forma autónoma.

## DEC-003 Privacidad de coordenadas

Las coordenadas públicas deben generalizarse cuando exista riesgo para sitios sensibles.
