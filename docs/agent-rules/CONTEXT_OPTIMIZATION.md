# CONTEXT OPTIMIZATION

Reglas adaptadas de la guía de ahorro de tokens entregada para este proyecto.

- El prompt contiene la tarea actual; el repositorio contiene el contexto permanente.
- Mantener `PROJECT_STATE.md` pequeño y actualizado.
- Mantener el historial en `PROJECT_JOURNAL.md`, no en el estado actual.
- Consultar context packs específicos en lugar de leer todo el repositorio.
- Separar `CURRENT` de `TARGET` para no implementar trabajo futuro accidentalmente.
- Usar alcance limitado, criterios de aceptación y `STOP` explícito.
- Revisar primero el diff y el estado antes de leer archivos completos.
- Verificar según el riesgo: TARGETED, DOMAIN, UI o FULL.
- Aplicar YAGNI y evitar sobrearquitectura.
- No continuar a la siguiente fase sin autorización.
