# DOMAIN CONTEXT

## Propósito

Registrar zonas, estructuras, corales, observaciones, mantenimiento y actividades para apoyar una evaluación preliminar y trazable.

## Estados de coral

Vivo, enfermo, blanqueado, perdido, pendiente de siembra y en observación.

## Estados de estructura

Estable, desplazada, dañada, enterrada y requiere mantenimiento.

## Límites

La plataforma no certifica viabilidad, no sustituye buceo científico, no diagnostica enfermedades y no autoriza intervenciones.
