# UI CONTEXT

## Dirección visual

Experiencia submarina inspirada en Isla Tortuga: azul profundo, turquesa, superficies luminosas, corrientes, vida marina decorativa y profundidad progresiva.

## Reglas

- No ocultar datos ni controles con animaciones.
- Respetar `prefers-reduced-motion`.
- No depender solo del color.
- El mapa siempre debe tener alternativa en lista.
- Probar 375 px, 768 px y 1280 px.
